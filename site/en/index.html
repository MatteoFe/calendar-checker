Calendar Checker

Chrome extension for Google Calendar

Calendar Checker is a Chrome extension that shows your Google Calendar events and manages reminders. It is a personal project built for the daily use of a single person, and it runs entirely in the browser: there is no server.

What it does

  • Shows the events of the calendars you choose in a month view, using each calendar's color.
  • Shows the time left to your next event on the toolbar icon, with a badge and a tooltip.
  • Opens a reminder window using the reminders you already set in Google Calendar, letting you snooze or dismiss them.

What data it uses

To work, it reads your calendar list and their events in read-only mode through Google's calendar.readonly access. It never creates, edits or deletes anything. Details are in the privacy policy.

Availability

The extension is not published on the Chrome Web Store and is not meant for public distribution. This page exists to describe the project and how it handles data.
